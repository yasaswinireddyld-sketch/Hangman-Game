# Hangman Game 🎮

A simple Hangman word guessing game built using Python and Flask.

## Features
- Multiple word categories
- Random word selection
- Letter-by-letter guessing
- 6 lives for each game
- Interactive keyboard
- Win and Game Over messages
- CSS-based user interface

## Technologies Used
- Python
- Flask
- HTML
- CSS

## How to Run

1. Clone this repository.
2. Install Flask:
   `pip install flask`
3. Run the application:
   `python3 app.py`
4. Open `http://127.0.0.1:5000` in your browser.
